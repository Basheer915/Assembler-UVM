# Ассемблер и интерпретатор УВМ

Проект реализует вариант 1 задания по учебной виртуальной машине. Программа
написана на Go и разрабатывается поэтапно.

## Этап 1: ассемблер CSV и промежуточное представление

Ассемблер читает CSV-файл с заголовком `command,operand`. Команды нечувствительны
к регистру:

| Команда | Операнд | Поля промежуточного представления |
| --- | --- | --- |
| `LOAD` | Константа от 0 до 131071 | `A=0`, `B=константа` |
| `READ` | Отсутствует | `A=5`, `B=0` |
| `STORE` | Адрес от 0 до 1023 | `A=2`, `B=адрес` |
| `ABS` | Отсутствует | `A=4`, `B=0` |

Пример входного файла (`examples/specification.csv`):

```csv
command,operand
LOAD,319
READ,
STORE,675
ABS,
```

Запуск ассемблера: укажите путь к входному файлу, путь к выходному файлу и при
необходимости включите режим тестирования:

```powershell
.\run.bat -input examples\specification.csv -output build\program.ir.json -test
```

Выходной файл содержит промежуточное представление в формате JSON. В режиме
тестирования поля каждой команды также выводятся в консоль. Это пока не
машинный код: его формирование будет реализовано на этапе 2.

Запуск тестов:

```powershell
go test ./...
```

## Этапы проекта

1. Разобрать команды CSV и преобразовать их в промежуточное представление.
2. Преобразовать промежуточное представление в машинный код.
3. Реализовать выполнение команд загрузки и работы с памятью, разделить память
   команд и данных, сохранять дамп памяти в формате XML.
4. Реализовать операцию `ABS`.
5. Выполнить требуемую задачу с вектором и подготовить примеры программ.
