# Ассемблер и интерпретатор УВМ

Вариант 1. Реализация на Go, этапы выполняются последовательно.

## Этап 1. CSV в промежуточное представление

Ассемблер разбирает команды `LOAD`, `READ`, `STORE`, `ABS` из
[примера CSV](examples/specification.csv) и переводит их в поля `A` и `B`.

## Этап 2. Машинный код

Запуск:

```powershell
.\run.bat -input examples\specification.csv -output build\program.bin -test
```

Команда кодируется тремя байтами. Для примера результат:
`F8 09 00 | 05 00 00 | 1A 15 00 | 04 00 00` (12 байт).
Режим `-test` выводит байты команд и размер файла.

Проверка:

```powershell
go test ./...
```

## Этап 3. Интерпретатор и память

Сборка и запуск программы копирования массива:

```powershell
go run ./src/cmd/assembler -input examples\copy_array.csv -output build\copy_array.bin
go run ./src/cmd/interpreter -input build\copy_array.bin -dump build\memory.xml -start 200 -end 202
```

Результат в XML-дампе: ячейки 200–202 содержат значения `7`, `12`, `24`.
